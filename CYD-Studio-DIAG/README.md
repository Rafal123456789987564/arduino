# CYD Studio DIAG 2.44

Edytor graficzny dla CYD ESP32 i M5Stack: LVGL 9.6, generator PlatformIO, kalibracja dotyku, testy Wokwi, FFT/CC1101.

**Uruchomienie (Windows):** pobierz katalog projektu; uruchom `URUCHOM_CYD_STUDIO.bat` lub `powershell -ExecutionPolicy Bypass -File .\START.ps1`.

**Status:** kod źródłowy wersji 2.44. Symulacja Wokwi i testy fizycznego LCD wymagają osobnej weryfikacji.

Dokumentacja i przykłady znajdują się w tym katalogu.
